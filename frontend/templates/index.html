Architectural Framework: Three Core Modules

Engineered according to modern distributed healthcare systems architecture.

Module 1

Mobile Sensing & User Interface

Collects vital biometrics (heart rate, step cadence, calories burned, sleep metrics) via HTML5 Web Sensors & wearable endpoints with interactive Apple Health-style dashboards.

  • Real-time Heart Rate & Zones
  • Step Count & Distance Estimation
  • Sleep Stages & Quality Score
Module 2

Cloud Storage & Analytics

Secures biometric records in Firebase Firestore with user-level isolation. Calculates BMI with clinical disclaimers, tracks 7-day Move trends, and executes dual Scikit-learn ML models.

  • Dual-Mode Firebase Firestore
  • Random Forest Activity Recognition
  • Isolation Forest Anomaly Detection
Module 3

Health Alerts & Emergency Notification

Automated rule engine detects tachycardia, bradycardia, severe sleep deficits, and ML-flagged anomalies. Dispatches multi-channel alerts (Push, SMTP Email, Twilio SMS) to emergency contacts.

  • Intelligent 15-min Debounce Logic
  • Multi-Contact Escalation Protocol
  • Test Emergency Mode for viva demos
